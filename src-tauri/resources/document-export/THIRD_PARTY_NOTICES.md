# Markune document export runtime notices

Markune invokes the following unmodified command-line programs as isolated
sidecars for professional document conversion. They are separate programs and
are not linked into the Markune process.

- Project: <https://pandoc.org/>
- Source: <https://github.com/jgm/pandoc/tree/3.10.1>
- Source archive: <https://hackage.haskell.org/package/pandoc-3.10.1/pandoc-3.10.1.tar.gz>
- License: GNU General Public License, version 2 or later, with the additional
  component notices recorded by the Pandoc project.

The verified build staging step places `Pandoc-COPYING.md` and
`Pandoc-COPYRIGHT` beside this notice in the application resources.
